# Berkeley_EE290
# Cellular Communication System Modeling under Mobility

A MATLAB-based system-level simulation framework for evaluating

cellular connectivity under high mobility.

The project investigates how user mobility, Doppler-induced

channel variation, network deployment density, and antenna

configuration affect wireless link quality and reliability.

Key performance metrics include:

- Signal-to-Interference-plus-Noise Ratio (SINR)

- Throughput

- Handover frequency

- Radio Link Failure (RLF)
